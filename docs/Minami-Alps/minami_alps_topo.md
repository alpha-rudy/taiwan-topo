=========================================================

AW3D30.OSM - Minami-Alps TOPO v__version__

適合用在 Garmin / Android / iOS 上的離線地圖。

## 地圖範圍

* 緯度範圍: N35.15 ~ N35.90
* 經度範圍: E137.70 ~ E138.65

本地圖涵蓋日本南阿爾卑斯（赤石山脈）全域，北起甲斐駒ヶ岳，南至光岳，包含白根三山、鳳凰三山與塩見・悪沢・赤石・聖岳主稜，東側涵蓋甲府盆地西緣與身延山地，西側達伊那谷南部與飯田。主要登山門戶為甲府・韮崎（廣河原、夜叉神峠）、伊那（北沢峠）、飯田（易老渡、鳥倉）與靜岡側的畑薙・井川。

### 著名的山頭 (Famous Peaks)

1. 北部：甲斐駒・仙丈・鳳凰
    * 甲斐駒ヶ岳 (Mount Kaikoma, 2,967m, 日本百名山, 花崗岩白峰，黑戶尾根為日本三大急登之一)
    * 仙丈ヶ岳 (Mount Senjo, 3,033m, 日本百名山, 「南阿爾卑斯的女王」，擁有三座冰河圈谷)
    * 鳳凰三山（日本百名山）：地藏岳 (2,764m, 著名的花崗岩塔「オベリスク」)、觀音岳 (2,841m)、藥師岳 (2,780m)
    * アサヨ峰 (2,799m, 早川尾根)

2. 白根三山（長野／山梨／靜岡縣界主稜北段）
    * 北岳 (Mount Kita, 3,193m, 日本第二高峰, 日本百名山, 特有種「北岳草」與大樺沢雪溪)
    * 間ノ岳 (Mount Aino, 3,190m, 日本並列第三高峰, 日本百名山)
    * 農鳥岳 (Mount Notori, 3,026m, 白根三山南端)

3. 中部：塩見・荒川・赤石
    * 塩見岳 (Mount Shiomi, 3,047m, 日本百名山, 黑色鐵盔造型的雙耳峰)
    * 悪沢岳（荒川東岳）(Mount Warusawa, 3,141m, 日本第六高峰, 日本百名山)
    * 赤石岳 (Mount Akaishi, 3,121m, 日本百名山, 山脈名稱的由來, 山頂有日本最高的一等三角點)

4. 南部
    * 聖岳 (Mount Hijiri, 3,013m, 日本最南端的三千公尺峰, 日本百名山)
    * 上河内岳 (2,803m)、茶臼岳 (2,604m)
    * 光岳 (Mount Tekari, 2,592m, 日本百名山, 偃松（ハイマツ）自然分布的南限)
    * 笊ヶ岳 (Mount Zaru, 2,629m, 日本二百名山, 白峰南嶺的展望名峰)

### 著名的健行路線 (Famous Trekking Routes)

1. 白根三山縱走（廣河原—北岳—間ノ岳—農鳥岳—奈良田，日本海拔最高等級的稜線縱走）
2. 甲斐駒ヶ岳・仙丈ヶ岳（北沢峠起登各一日往返；甲斐駒黑戶尾根為標高差 2,200m 的日本三大急登之一）
3. 鳳凰三山縱走（夜叉神峠—藥師岳—觀音岳—地藏岳—御座石鉱泉／青木鉱泉）
4. 塩見岳（鳥倉登山口—三伏峠—塩見岳，經日本最高峠之一的三伏峠）
5. 荒川三山—赤石岳環走（椹島起登，千枚岳—悪沢岳—荒川中岳—赤石岳，東海フォレスト山岳巴士接駁）
6. 聖岳—光岳縱走（易老渡・便ヶ島起登，經聖平小屋、上河内岳、茶臼岳、光小屋）
7. 仙塩尾根（仙丈ヶ岳—塩見岳之間的深遠稜線，「南阿爾卑斯的脊樑」）
8. 南阿爾卑斯全山縱走（甲斐駒ヶ岳→光岳，約 7–10 天，日本最長級的三千公尺稜線縱走）

### 著名景點

* 南阿爾卑斯林道巴士（仙流荘—北沢峠）與戸台河原
* 廣河原與夜叉神峠（甲府側門戶）、芦安溫泉
* 椹島與畑薙第一水壩（靜岡側門戶，畑薙大吊橋為日本屈指的高吊橋）
* 大井川鐵道井川線（日本唯一的齒軌式登山鐵道）與井川湖、接岨峽溫泉
* 寸又峽溫泉與夢之吊橋
* 身延山久遠寺（日蓮宗總本山，樹齡四百年的枝垂櫻）
* 下栗の里（遠山鄉的「日本のチロル」天空聚落）
* 大鹿村中央構造線露頭與鹿塩溫泉（罕見的內陸強鹽泉）

### 歷史事件

* 江戶時代的信仰登山：甲斐駒ヶ岳於 1816 年由弘幡行者（小尾権三郎）開山，黑戶尾根沿線至今保存大量石祠與靈神碑；鳳凰山地藏岳的賽之河原自古為求子信仰之地。
* 1892 年英國傳教士威斯頓 (Walter Weston) 攀登甲斐駒ヶ岳與鳳凰山等峰，將南阿爾卑斯介紹給世界；1905 年他與小島烏水等人共同創立日本山岳會，南阿爾卑斯諸峰的近代探勘與開發也在此時期展開。
* 1957 年井川水壩完工：為興建水壩鋪設的大井川鐵道井川線後來轉為觀光鐵道，成為進入南阿爾卑斯深南部的重要通道。
* 1964 年南阿爾卑斯國立公園指定，涵蓋山梨、長野、靜岡三縣的主稜地帶。
* 2014 年南阿爾卑斯登錄為聯合國教科文組織生態園區（UNESCO Eco Park），表彰其三千公尺稜線與山麓聚落共存的自然文化景觀。
* リニア中央新幹線南阿爾卑斯隧道：2010 年代起於山脈正下方開挖的長大隧道，因大井川水量減少疑慮引發靜岡縣的長期爭議，是日本重大的環境議題之一。
