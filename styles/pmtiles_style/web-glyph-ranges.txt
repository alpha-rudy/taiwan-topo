# 4.7.1 the test is /\p{Ideo}|\p{sc=Hang}|\p{sc=Hira}|\p{sc=Kana}/u. Every
# other character needs its glyph range: CJK punctuation and full-width forms

# read fails the whole tile, so the page gets every range holding at least one
# assigned character (outside private use) that the test does not match.
